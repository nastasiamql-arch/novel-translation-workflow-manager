# Palantir: Novel 3.10.0 — Polish History & Recovery

- **Polish History:** หน้าเต็มภายในโปรแกรม แสดงช่วงบท วันเวลา และจำนวนไฟล์จริง
  พร้อมค้นหา Refresh และปุ่มหลัก **คัดลอก** ในแต่ละรายการ
- **Automatic Stage Snapshot:** คลิกปุ่มชื่อขั้นตอนเดิมเพื่อบันทึกไฟล์ก่อนคัดลอก
  เลือกขั้นตอนที่เปิดใช้ผ่าน Settings โดยผูกกับ Step ID ไม่ผูกกับลำดับหรือชื่อ
- **Chapter Range History:** รองรับช่วงบทที่ไม่เท่ากัน อ่านหัวบทจากไฟล์เนื้อหาที่ระบุได้
  หากยืนยันไม่ได้ ให้กรอกช่วงบทเอง ไม่เดาจาก Context และไม่มีจำนวนบทต่อรอบตายตัว
- **One-click Copy Recovery:** เรียกคืนไฟล์ Snapshot ชุดเดิมในคลิกเดียว
  โดยไม่เขียนทับ Context จริง ไม่เพิ่ม Export Count และไม่เลื่อน Workflow
- **Per-Novel History Folder:** เก็บใน `Main Folder/Polish History` ของนิยายแต่ละเรื่อง
  แยก Step ID และ Novel ID พร้อม Manifest, ขนาดไฟล์ และ SHA-256
- **All Stage Files Clipboard:** รวมไฟล์ Enabled/Disabled, Folder Attachment,
  Dynamic Reference และ External File พร้อม Context ณ เวลาบันทึก
  รักษาทุกไบต์ Encoding/BOM, Unicode, Space, Tab, บรรทัดว่าง และ Binary
- **Recovery After Restart:** ประวัติอ่านจาก Disk ใช้ได้หลังโปรแกรมปิดหรือคอมดับ
  เก็บ Snapshot เก่าทุกเวอร์ชัน ตรวจไฟล์ก่อนคัดลอก และแสดงประวัติเสียหายเพื่อให้ตรวจสอบ
- **ZIP Compatibility:** รองรับ Windows File Clipboard แบบหลายไฟล์และ ZIP setting เดิม
  ไฟล์ที่เผยแพร่ไป Clipboard คงอยู่หลังปิดโปรแกรม

ตั้งค่าโฟลเดอร์หลักและขั้นตอนใน **Settings → Novel / Workflow** แล้วคลิกชื่อขั้นตอน
กด **ประวัติ** เพื่อคัดลอกชุดเดิม หากคัดลอกข้อมูลชุดใหม่ที่ยืนยันช่วงบทไม่ได้ ให้กรอกช่องช่วงบท

Windows Installer ใช้ระบบอัปเดตเดิมและติดตั้งในตำแหน่งเดิม ข้อมูลนิยาย Context,
Settings และ Snapshot ยังคงอยู่ ตรวจสอบผ่าน Windows CI รวมการดาวน์โหลด Release
ด้วย updater, size/SHA-256 และการติดตั้งอัปเกรดจาก 3.9.0
