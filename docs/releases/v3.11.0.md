# Palantir: Novel 3.11.0 — บันทึกไฟล์รอตรวจ

- เพิ่มปุ่ม **บันทึกไว้รอตรวจ** สำหรับบันทึกไฟล์ของขั้นตอนที่กำหนดไว้ใน Novel Profile
  โดยไม่เริ่ม Workflow ไม่แตะ Clipboard และไม่เปลี่ยนตัวนับ Export
- บันทึก Snapshot อัตโนมัติหลัง TXT Export สำเร็จ พร้อมแสดงผลแยกจากผล Export
  และเก็บรายการ `รอระบุช่วงบท` เมื่อยืนยันเลขบทจากไฟล์ที่ส่งออกไม่ได้
- สำรองเฉพาะไฟล์ที่ผู้ใช้ผูกกับขั้นตอนนั้น รวมไฟล์ Disabled, Dynamic Reference,
  External File และ Folder Attachment; Context จะรวมเมื่อแนบกับขั้นตอนเองเท่านั้น
- ใช้โฟลเดอร์ `<ชื่อขั้นตอน> บท <ช่วงบท>` เช่น `ตรวจคำแปล บท 6-10` และคง
  ประวัติที่ย้ายมาจากโครงสร้าง v3.10.0/v3.10.1 หลังตรวจ Manifest และ Hash
- เพิ่มสถานะ `รอตรวจ` / `ตรวจแล้ว` ในหน้า History เดิม และคงการคัดลอกแบบไฟล์หลายไฟล์
  หรือ ZIP ตามการตั้งค่าเดิม

Windows Installer รองรับ In-app Update และทดสอบอัปเกรดจาก v3.10.1 ใน CI.
