# Palantir: Novel v3.13.2

- Polish History rows now display continuous numbers after a row is deleted. Immutable snapshot identities remain unchanged.
- A corrected file inside Polish History no longer permanently disables Copy. After an explicit confirmation, the app validates files, preserves the original manifest hashes in a backup, updates SHA-256 and size for intentionally changed payloads, then copies.
- Missing files and other integrity/ownership problems still block copying and are never silently approved.
- Includes regression coverage and Windows installer in-place upgrade verification from v3.13.1.
