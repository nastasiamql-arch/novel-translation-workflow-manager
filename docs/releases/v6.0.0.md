# v6.0.0 — Remove the optional AI Web Workspace

This release removes the Gemini multi-tab/browser AI Web Workspace introduced in v5.x. This is a breaking feature removal, hence the major version increment from v5.12.0 to v6.0.0.

- Removed the AI Workspace navigation, screens, job handler, manual-result adapter, browser workers, Chrome profile launcher and automated browser support.
- Removed the Playwright runtime dependency and Windows bundling, its dedicated tests and the Chrome smoke CI step.
- Retained novel Library and Workspace, Translation Batches, COPY STEP, COPY ZIP, Vocabulary and Glossary, Translator, Context, Polish History, Export, Planner, Inspector, Recovery and the GitHub updater.
- Windows in-place upgrade cleans only known obsolete runtime files within the install directory. It does **not** delete any private legacy AI jobs, cached Gemini responses or Chrome profile data. Legacy profile/session data remains readable by the original workflow.

Use the application updater or the versioned Windows installer to upgrade from v5.12.0.
