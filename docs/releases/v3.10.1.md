# Palantir: Novel 3.10.1 — ชื่อโฟลเดอร์ Polish History

- เปลี่ยนโฟลเดอร์ประวัติเป็น `Polish History/<ชื่อขั้นตอน>-บท <ช่วงบท>` โดยตรง
  เช่น `ตรวจคำแปล-บท 6-10` ไม่มีโฟลเดอร์รหัสซ้อนหรือ UUID ในชื่อประวัติ
- ช่วงเดิมที่เนื้อหาเปลี่ยนจะเก็บแยกด้วยวันเวลาและลำดับ `(2)`, `(3)` เมื่อจำเป็น
  หลายโปรไฟล์ใช้โฟลเดอร์ร่วมกันได้ โดยใช้ชื่อโปรไฟล์ต่อท้ายเมื่อชื่อชนกัน
- ประวัติ v3.10.0 ยังอ่านและคัดลอกได้ เปิด History หรือ Refresh เพื่อย้ายประวัติ
  หลังตรวจ Manifest, Profile/Step และ SHA-256 ครบ ก่อนและหลังย้าย
  ไม่แก้ชื่อไฟล์ เนื้อหา Timestamp, ID หรือ Manifest เดิมในการ Migration
- หาก Clipboard ยังอ้าง Path เดิม หรือย้ายไม่สำเร็จ จะคงข้อมูลพร้อมแจ้งสถานะ
  เมื่อแก้ช่วงบทจะเปลี่ยนชื่อโฟลเดอร์ด้วย โดยป้องกัน Clipboard ที่กำลังใช้งาน
- คงหน้า History, ปุ่มชื่อขั้นตอน, Clipboard หลายไฟล์/ZIP, Editor, AutoSave,
  Context, Export Counter และ Workflow เดิม

Windows Installer รองรับ In-app Update เดิมและอัปเกรดจาก 3.10.0 ในตำแหน่งเดิม
Windows CI ตรวจการรักษาข้อมูลนิยายและ Migration ประวัติเดิมโดยเปรียบเทียบ Hash
ของ Manifest และ Payload ทุกไฟล์ พร้อมตรวจการดาวน์โหลด Release ผ่าน Updater
