# Palantir: Novel

## Logo และ App Icon

โปรแกรมใช้สัญลักษณ์ **N Monogram** ตามแบบที่เลือก: ตัว N ทรงเรขาคณิตสีเดียวบนพื้นเรียบ ออกแบบให้จำง่ายและยังอ่านออกเมื่อย่อเป็น favicon พร้อมเวอร์ชันสำหรับพื้นหลังอ่อนและเข้ม

- SVG ต้นฉบับแบบพื้นหลังโปร่งใสและแบบ App Icon อยู่ใน `assets/brand/`
- PNG สำหรับ favicon 16, 32 และ 48 px, desktop/mobile 256, 512 และ 1024 px อยู่ใน `assets/brand/exports/`
- `assets/palantir_novel.ico` มีขนาด 16–256 px และเป็นไอคอนที่ใช้สร้างตัวติดตั้ง Windows

## บันทึกไฟล์

ไฟล์ที่เปิดใน Editor จะบันทึกเป็น UTF-8 ผ่านไฟล์ชั่วคราวในโฟลเดอร์เดียวกัน ก่อนแทนที่ไฟล์เดิมเมื่อเขียนครบ หาก Windows ล็อกไฟล์ การบันทึกจะคงไฟล์เดิมไว้ แสดงสถานะว่ายังบันทึกไม่สำเร็จ และลอง Auto Save ซ้ำเมื่อไฟล์พร้อม

## Workflow หาศัพท์แบบไฟล์ (เหมือน v1.12.0)

ขั้น **หาศัพท์** เป็นขั้น Workflow สำหรับจัดการไฟล์ศัพท์และใช้ `COPY STEP` ร่วมกับไฟล์อื่นในขั้นตอน ไม่มีแผง AI, การเชื่อมต่อ Provider, การดึงรายชื่อโมเดล หรือการเรียก API เพื่อสร้าง/เกลาศัพท์

ไฟล์ศัพท์และรายการของขั้นหาศัพท์ในโปรไฟล์เดิมยังคงอยู่ โปรแกรมจะเก็บข้อมูลตั้งค่าและขั้น “เกลาศัพท์” จากรุ่นใหม่ไว้เป็นข้อมูลเก่าที่ไม่เปิดใช้งาน และไม่ลบไฟล์บนดิสก์

## Migration และออก release

โปรไฟล์เดิมยังเปิดได้ โดยย้ายขั้น “หาศัพท์” จาก workflow เก่าเข้าสู่ช่องขั้นหาศัพท์เฉพาะเมื่อจำเป็น และเก็บไฟล์แนบไว้ ระบบ self-updater และ installer AppId เดิมยังใช้ได้

ทดสอบด้วย `python -m pytest -q` และ `python tests/ui_smoke.py` แล้ว build ด้วย `./build_windows.ps1` (Python 3.11+ สำหรับอ่าน TOML ใน build script และ Inno Setup 6) เผยแพร่ผ่าน CI เดิม: merge commit บน `main` ที่มี `[release]` จะสร้าง tag ตามเวอร์ชันใน `pyproject.toml` และ GitHub Release พร้อม installer หลัง release เผยแพร่ ผู้ใช้กด **ตรวจสอบอัปเดต** ในโปรแกรมเดิมได้ Draft PR ยังไม่เผยแพร่ release

## หน้าตาและการใช้งาน

- หน้าตาโปรแกรมใช้สีเทากลางแบบมินิมอลทั้งพื้นหลัง แถบนำทาง จุดโฟกัส การเลือกข้อความ และสถานะ พร้อมธีม Dark และ Light; ใช้สีเฉพาะเพื่อแยกสถานะสำเร็จ คำเตือน และข้อผิดพลาด
- สีและสถานะของคลังนิยาย แถบเครื่องมือ Editor แท็บ หน้าต่างย่อย กล่องแจ้งเตือน และตัวบ่งชี้ความคืบหน้าใช้ design tokens ชุดเดียวกัน
- ตัวอักษรพื้นฐานใหญ่ขึ้น พร้อมสี disabled ที่ยังอ่านได้ จุดโฟกัสแป้นพิมพ์ชัดเจน และพื้นที่กดของปุ่ม/ช่องกรอกกว้างขึ้น
- คงพื้นผิวเรียบและลำดับหน้าเดิม โดยแถบเครื่องมือ Editor เลื่อนได้เมื่อหน้าต่างแคบ และแถบข้างยังซ่อนหรือปรับขนาดได้
- หน้าต่างอัปเดตแสดงเปอร์เซ็นต์เพียงตำแหน่งเดียว ข้อความไม่เบียดแถบความคืบหน้า และปุ่มยกเลิกมองเห็นชัด
- **Novel Library** แสดงโปรไฟล์พร้อมรูปปกและช่องค้นหา โดยเน้นสีเมื่อชี้หรือเลือกเรื่อง
- แยกนิยายในคลังเป็น **กำลังแปล**, **พักแปล**, และ **ชนต้นฉบับแล้ว** ได้จากปุ่มในหน้าทำงาน โดยเก็บไฟล์และความคืบหน้าเดิมไว้
- เมื่อเปิดเรื่อง แถบด้านข้างรวมขั้นตอนการแปลและไฟล์ของขั้นตอนที่เลือกไว้ข้าง Editor ซึ่งใช้พื้นที่หลักของหน้าต่าง
- ปรับฟอนต์และการเรนเดอร์ข้อความบน Windows ให้เหมาะกับภาษาไทยมากขึ้น พร้อม fallback ไปยัง Leelawadee UI / Segoe UI
- Editor ใช้ Cascadia Code / Consolas เมื่อมีในเครื่อง และมี fallback ภาษาไทยเพื่อให้อ่านตัวอักษรไทยได้คมขึ้น
- Editor บันทึกอัตโนมัติหลังหยุดพิมพ์ 1 วินาที แสดงสถานะ save, จำนวนคำ/อักขระ และความคืบหน้าที่ status bar
- กด `Ctrl+H` เพื่อค้นหาในไฟล์ พร้อมไฮไลต์ผลลัพธ์และปุ่มก่อนหน้า/ถัดไป
- ปุ่มคลังนิยายใช้สลับเรื่อง และแถบด้านข้างสามารถซ่อน ปรับขนาด และค้นหาบทหรือไฟล์ได้

Palantir: Novel คือโปรแกรมเดสก์ท็อปสำหรับ Windows ที่รวมการเปิดโปรเจกต์แบบ Novel Launcher เข้ากับระบบเวิร์กโฟลว์สำหรับงานแปลนิยายที่ปรับแต่งได้ แต่ละเรื่องจะแยกโปรไฟล์ออกจากกัน และโปรแกรมสามารถเปิดโฟลเดอร์โปรเจกต์ ไฟล์ โปรแกรม และเว็บไซต์ที่กำหนดไว้สำหรับแต่ละเรื่อง รวมถึงเปิดเป็นกลุ่ม และจดจำลำดับไฟล์ที่ใช้ในแต่ละขั้นตอนการแปล

เวอร์ชัน 1 ยังไม่มีการเรียกใช้ AI API หรือ Translation API โดยตรง

## ดาวน์โหลดและใช้งานบน Windows

1. เปิดหน้า [GitHub Releases](https://github.com/nastasiamql-arch/novel-translation-workflow-manager/releases)
2. ดาวน์โหลดตัวติดตั้ง `NovelWorkflow-Setup-<version>.exe` จาก Release ล่าสุด
3. เปิดไฟล์ติดตั้ง แล้วทำตามขั้นตอนบนหน้าจอ จากนั้นเปิด Palantir: Novel จาก Start Menu หรือ Desktop shortcut

ตัวติดตั้ง Release มีโปรแกรมและ Qt runtime ที่จำเป็นรวมมาให้แล้ว จึงไม่ต้องติดตั้ง Python เพิ่ม ปุ่ม **Code → Download ZIP** ใช้ดาวน์โหลดซอร์สโค้ดสำหรับนักพัฒนา ไม่ใช่ตัวติดตั้ง ส่วน Build ล่าสุดจากการอัปเดต branch `main` สามารถดาวน์โหลดได้จาก GitHub Actions ในหัวข้อ **Artifacts**

## รันจากซอร์สโค้ด

ต้องใช้ Python 3.10 หรือใหม่กว่า เปิด PowerShell ในโฟลเดอร์ repository แล้วรัน:

    .\build_windows.ps1

คำสั่งนี้จะสร้างตัวโปรแกรมด้วย PyInstaller และแพ็กเป็นตัวติดตั้ง `dist/NovelWorkflow-Setup-<version>.exe` ด้วย Inno Setup 6

ถ้าต้องการรันจาก Python โดยตรง ให้สร้าง environment ติดตั้งโปรแกรม แล้วจึงเปิดใช้งาน:

    py -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -e .
    .\.venv\Scripts\python.exe -m novel_workflow.main

## ฟีเจอร์ Launcher

- กำหนดโฟลเดอร์หลัก รวมถึงโปรแกรม ไฟล์ โฟลเดอร์ และเว็บไซต์สำหรับนิยายแต่ละเรื่องได้
- เปิดรายการที่เปิดใช้งานอยู่ทั้งหมดของเรื่องปัจจุบันได้ในครั้งเดียว
- สร้างกลุ่มนิยาย แล้วเปิดทั้งกลุ่มได้ด้วยคำสั่งเดียว
- ตั้งรูปปกแยกสำหรับนิยายแต่ละเรื่องได้ โดยรูปปกจะถูกคัดลอกไปเก็บในข้อมูลของโปรไฟล์นั้น
- ข้อมูล Workflow จะผูกอยู่กับแต่ละโปรไฟล์

ตั้งแต่เวอร์ชัน 1.1 โปรแกรมใช้พื้นที่ข้อมูลใหม่ที่ `%LOCALAPPDATA%/NovelWorkflow` เพื่อเริ่มต้นแบบโปรแกรมใหม่โดยไม่มีข้อมูลนิยายเดิม ข้อมูลเก่าที่ `%LOCALAPPDATA%/NovelTranslationWorkflowManager` จะไม่ถูกลบและจะไม่ถูกโหลดอัตโนมัติ

## ฟีเจอร์ Workflow

สามารถสร้างโปรไฟล์นิยายแยกกัน ปรับแต่งขั้นตอน Workflow แนบไฟล์ตามลำดับหรืออ้างอิงบทแบบ Dynamic ดูตัวอย่างข้อความที่ประกอบแล้ว และคัดลอกไฟล์ที่เลือกไปยัง Clipboard ได้

การเพิ่มไฟล์ด้วย **Add File** จะลิงก์ไปยังไฟล์ต้นฉบับโดยตรง ดังนั้นหากแก้ไฟล์จากภายนอกโปรแกรม การเปลี่ยนแปลงจะถูกอ่านเข้ามาทันที

รองรับ Dynamic Reference ได้แก่ `CURRENT_SOURCE_CHAPTER`, `CURRENT_TRANSLATED_CHAPTER` และ `CURRENT_REVIEWED_CHAPTER` โดยไฟล์บทสามารถใช้ชื่ออะไรก็ได้ ตราบใดที่ชื่อไฟล์มีเลขบทอยู่

## ความคืบหน้าการแปล

- หน้าความคืบหน้าจะแสดงจำนวนบทที่ทำเสร็จวันนี้ สัปดาห์นี้ และในช่วง 7 วันที่ผ่านมา พร้อมยอดรวมแยกตามนิยายแต่ละเรื่อง
- ตั้งเป้าหมายจำนวนบทสำหรับนิยายแต่ละเรื่องได้ หากแก้ไขเป้าหมายเดิม โปรแกรมจะเก็บเลขบทเริ่มต้นไว้เพื่อไม่ให้ความคืบหน้าที่มีอยู่หายไป
- ตั้งเป้าหมายเดียวให้ทุกเรื่องที่กำลังแปลและเชื่อม Context ได้จากหน้าความคืบหน้า และเริ่มนับรอบใหม่อัตโนมัติเมื่อทำครบ โดยเก็บส่วนที่เกินไว้เป็นความคืบหน้ารอบถัดไป
- Palantir: Novel จะตรวจไฟล์ Context ของแต่ละโปรไฟล์ตอนเปิดโปรแกรมและทุก ๆ 10 วินาที หากหัวข้อล่าสุดใน Context เปลี่ยนจาก `บทที่ 125` เป็น `บทที่ 130` โปรแกรมจะบันทึกว่าแปลเพิ่มแล้ว 5 บท
- กิจกรรมรายวันจะอิงจากเวลาที่ไฟล์ Context ถูกแก้ไขล่าสุดตามเวลาท้องถิ่นของคอมพิวเตอร์ โปรแกรมจะเก็บ checkpoint และกิจกรรมแยกตามแต่ละโปรไฟล์ ป้องกันการนับบทเดิมซ้ำในวันเดียวกัน และจะตั้งฐานใหม่เมื่อเปลี่ยนไฟล์ Context หรือเลขบทลดลง
- การตรวจครั้งแรกจะใช้สำหรับตั้งค่าเริ่มต้น ไม่ได้นับประวัติทั้งหมดของนิยายเป็นผลงานของวันนี้ หากมีการแก้ Context หลายวันในช่วงที่โปรแกรมปิดอยู่ ไฟล์จะเก็บเวลาแก้ไขล่าสุดเพียงครั้งเดียว จึงไม่สามารถแยกย้อนหลังได้ว่าการเปลี่ยนแปลงเกิดขึ้นในวันใดบ้าง
